02 — HOW IT WORKS

One number in, a whole skyline out.

No assets, no models, no build step. A seeded random generator and a noise field decide everything, and the GPU does the rest.

SEED → SKYLINE

Grown, not modelled

A 30 × 30 street grid is split into lots. A noise field and distance from downtown set each tower's height, setbacks, spire and facade style.

16,000 CARS · 2 DRAW CALLS

Traffic flown by the GPU

Every car is a lane, a speed and a phase. The vertex shader places all of them each frame; the CPU repeats the same math only for the car you click.

~1.4M WINDOWS · 0 TEXTURES

Windows from a hash

Facades draw their window grid in the fragment shader. Rooms switch on by hash, and far grids blend to their average so the skyline never shimmers.
